Rekomendasi Arsitektur & Pengembangan Fitur Lanjutan

Aplikasi MasjidKu dirancang siap dikembangkan lebih jauh tanpa biaya bulanan (100% Free Stack: GitHub, Vercel & Firebase Free Tier). Berikut adalah modul-modul yang sangat direkomendasikan untuk pengembangan sistem masjid tingkat lanjut:

1. Modul Zakat & Mustahik

Pencatatan penerimaan Zakat Fitrah/Mal, perhitungan beras & uang, pendataan 8 asnaf mustahik di lingkungan masjid, serta cetak bukti kwitansi zakat.

2. Mode TV Display Masjid (Digital Signage)

Tampilan layar TV masjid khusus berisi Jam Shalat Realtime, Countdown Iqomah, Running Text Pengumuman, dan Slide Poster Kajian secara otomatis.

3. Modul Layanan Ambulans & Rukun Kematian

Pengelolaan iuran rukun kematian warga, jadwal piket pengemudi ambulans masjid, dan inventaris perlengkapan jenazah.

4. Integration QRIS Dinamis & WhatsApp Gateway

Generasi QRIS otomatis untuk donasi hajat tertentu dan pengiriman pengumuman jadwal kajian langsung ke grup WhatsApp jamaah.

Panduan Deploy 100% Gratis (GitHub + Vercel + Firebase)

Status Saat Ini: Aplikasi menggunakan LocalStorage secara otomatis sehingga langsung fungsional tanpa backend!

Langkah 1: Hosting di GitHub & Vercel (Gratis)

  1. Buat Repository baru di GitHub.com (misal: masjidku-app).
  2. Upload file HTML ini (simpan dengan nama index.html).
  3. Buka Vercel.com, login dengan GitHub, lalu pilih Import Repository.
  4. Klik Deploy. Aplikasi MasjidKu Anda langsung live dengan HTTPS gratis!

Langkah 2: Hubungkan Firebase Firestore (Opsional untuk Multi-User)

  1. Buka console.firebase.google.com dan buat project gratis baru.
  2. Aktifkan Firestore Database (mode Test).
  3. Copy `firebaseConfig` Anda dan masukkan ke skrip aplikasi ini.
